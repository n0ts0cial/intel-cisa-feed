# Vulnerability Reports Archive 🗄️

This directory serves as the historical repository for all daily intelligence reports generated by the **CISA KEV Intelligence Feed**.

## 📁 Directory Structure

Reports are named using the ISO 8601 date format: `YYYY-MM-DD.md`.  
This allows for easy chronological sorting and quick lookup of specific dates.

## 🔍 How to use these reports

Each file in this folder contains a detailed breakdown of vulnerabilities that were officially recognized as "Known Exploited" by CISA on that specific date. 

### Key Information included:
- **Prioritization:** Use the `baseScore` and `baseSeverity` (enriched by NIST) to prioritize patching efforts.
- **Urgency:** Pay close attention to the `requiredAction` field, which contains CISA's official deadlines for federal agencies (a gold standard for private sector timelines as well).
- **Evidence:** The `hasPublicExploit` field indicates if a Proof-of-Concept or exploit code is already circulating in the wild.

## 📈 Data Sources
- **CISA KEV:** Source for the list of actively exploited CVEs.
- **NIST NVD API:** Source for CVSS metrics and technical references.

## ⚠️ Disclaimer
These reports are generated automatically. Always cross-reference with official vendor advisories before applying critical patches in production environments.
